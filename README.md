# 墨水屏日历 · 使用说明（content.md）

> 配套文档：更新内容见 [`content1.md`](content1.md)
> 当前版本：**v1.2.0**（versionCode 4）　包名：`com.breeze.epd`

---

## 一、这是什么

墨水屏日历是一款**完全离线**的安卓原生应用，用来给电子价签（墨水屏日历 / 时钟屏）**推时间、推日历、推图片、推文字**。

- 不是网页套壳，是纯原生 Kotlin + Android View 实现，**不加载任何网页、不联网**
- 没有申请 `INTERNET` 权限，App 内不存在任何网络请求
- 界面、字体、图标全部自制，零 emoji，全部用矢量图标

支持的设备是市面上常见的三种蓝牙墨水屏价签，**按蓝牙名前缀自动识别并切换界面与协议**：

| 蓝牙名前缀 | 设备类型 | 屏幕 | 能做什么 |
|---|---|---|---|
| `NRF-EPD-` | 带灯日历价签 / 挂件版（nRF52） | 2.13 / 2.9 / 4.2 寸，黑白或黑白红 | **功能最全**：日历、时钟、图片、文字、多图槽位轮播、主题、LED、温度校准 |
| `DLG-` | 黑白纯时钟价签（Dialog DA14585） | 2.13 寸黑白 | **纯时钟**：同步时间、12/24 小时制、时间校准、电压读取 |
| `ESL-` | 汉朔三色价签（Telink TLSR8359） | 2.13 寸黑白红 | 传图、文字、日历/时钟模式、时钟样式 |

> 扫描时**只显示以上三类价签**，其它蓝牙设备（手环、耳机、键鼠等）会被直接过滤掉，不会出现在列表里。

## 二、安装

1. 拿到 `墨水屏日历_vX.Y.Z.zip`（内容与同名 `.apk` 完全一致，只是改了后缀，方便下载）；
2. 用文件管理器解压，得到 `墨水屏日历_vX.Y.Z.apk`；
3. 点开安装。首次安装需要在系统里允许「安装未知来源应用」；
4. 建议把应用图标添加到桌面，并**关闭电池优化**（否则息屏后蓝牙会被系统掐断）。

**系统要求**

| 项目 | 要求 |
|---|---|
| 最低系统 | Android 8.1（API 27） |
| 目标系统 | Android 14（API 34），已在 Android 10 / 14 上适配 |
| 架构 | armeabi-v7a / arm64-v8a / x86 / x86_64 四套原生库均已打包，可在设置里切换 32/64 位 |
| 权限 | 蓝牙（Android 12+ 用 BLUETOOTH_SCAN / CONNECT）、Android 11 及以下的定位（系统强制要求） |

**关于权限**：只在真正需要时才申请。Android 12 及以上扫描需要蓝牙权限；Android 11 及以下系统把蓝牙扫描和定位绑定，没开定位就搜不到设备，App 会引导你一键开启。

## 三、快速上手

```
打开 App  →  点「连接」  →  在搜索页选中你的价签  →  回到主页
```

1. **连接**：主页点「连接」进入全屏蓝牙搜索页，列表只显示价签，右边是信号强度图标和 RSSI 值，点一下即可连接；
2. **出画面**：主页「设备控制」里
   - 「日历模式」= 推送日历页（可先用「选择日期」指定某一天）
   - 「时钟模式」= 推送时钟页（会弹一次确认，这是全 App 唯一保留的确认框）
   - 「清除屏幕」= 立刻清屏，不再二次确认
3. **换内容**：「屏幕内容」卡片里
   - 「导入图片」= 选一张图 → 选面板尺寸/颜色模式/抖动算法 → 预览 → 直接写到屏上或存进槽位
   - 「新建文本」= 输入文字、调字号和颜色 → 直接写到屏上
   - 「图片槽位」= 管理设备内置 Flash 里的多张图片，可显示、删除、设置轮播间隔

## 四、功能详解

### 4.1 蓝牙搜索

- 全屏搜索页，**竖排列表**：左侧设备图标，中间设备名 + MAC 地址，右侧信号强度图标 + 实时 RSSI
- 只保留厂家价签（`DLG-` / `NRF-EPD-` / `ESL-`），其余设备连名字都不会显示
- 搜不到时才会提示开启蓝牙 / 定位，并给出跳转按钮
- 扫描在页面回到前台时才真正开始，不会出现「开了没反应」

### 4.2 设备控制（按设备家族自动变化）

| 功能 | NRF（带灯日历价签） | DLG（黑白时钟） | ESL（汉朔三色） |
|---|---|---|---|
| 日历模式 | ✅ | ❌ 纯时钟无日历 | ✅ |
| 时钟模式 | ✅ | ✅（按钮显示为「同步时间」） | ✅ |
| 清除屏幕 | ✅ | ❌ | ✅ |
| 选择日期 | ✅ | ❌ | ✅ |
| 12/24 小时制 | — | ✅ | — |
| 电池电压显示 | — | ✅ | — |
| 时钟样式 | — | — | ✅（样式 1~4） |

### 4.3 屏幕内容

**导入图片**

- 面板尺寸：2.13 寸黑白 104×212 / 2.13 寸三色 122×250 / 2.9 寸三色 128×296 / 4.2 寸三色 400×300；设备上报实际分辨率时会自动匹配
- 颜色模式：双色（黑白）/ 三色（黑白红）/ 四色（黑白红黄）
- 抖动强度：0 ~ 5，步进 0.1
- 支持一键「旋转 90°」，预览与实际下发完全一致
- 可以「发送到屏幕」或「保存到槽位」

**抖动算法**（默认 Floyd-Steinberg，观感最好）

| 算法 | 说明 |
|---|---|
| **无抖动（纯黑白）** | 不做任何误差扩散，直接量化，输出**只有纯黑/纯白（或纯红）**，画面里不会出现任何灰度 |
| **Floyd-Steinberg（默认·推荐）** | 经典误差扩散，细节保留最好，和原厂网页上位机默认一致 |
| Atkinson | 误差扩散更快，噪点更少 |
| Stucki | 细节更多，颗粒感略强 |
| Jarvis-Judice-Ninke | 最平滑，边缘最干净，速度最慢 |
| Bayer 有序抖动 | 8×8 有序矩阵，规则纹理，适合文字和几何图形 |

**新建文本**

- 输入多行文字，字号 8~80，颜色可选黑 / 白 / 红 / 黄
- 右侧实时预览，到屏效果与预览一致

**图片槽位（设备内置 Flash）**

- 读取设备上报的槽位数量、占用位图、当前槽位、步长
- 逐槽「显示」/「删除」
- 轮播间隔：0 = 关闭，最小 5 分钟，最大 10080 分钟（7 天），超过 255 分钟自动改用 2 字节格式下发

### 4.4 设备选项（设置页）

| 选项 | 适用 | 说明 |
|---|---|---|
| 时钟 LED 闪烁 | NRF | 不闪烁 / 每分钟 / 每 5 分钟 / 每 10 分钟 / 每 15 分钟 / 每 30 分钟 / 每小时 |
| **修复时间更新闪烁** | NRF | 见下方说明 |
| 蓝牙广播 | NRF | 关闭 / 每小时开 5 分钟 / 每 10 分钟开 1 分钟 / 常开（选「关闭」会直接断链） |
| 日历主题 | NRF | 4 套主题 |
| 时钟主题 | NRF | 3 套主题 |
| 温度校准偏移 | NRF | ±℃，立即生效 |
| 时钟样式 | ESL | 样式 1~4 |
| 12/24 小时制 | DLG | 切换时制 |
| 时间校准 | DLG | ±秒，直接写入设备基准时间 |

> **关键提示**：主题、LED 这类命令**只改配置、不会立刻重画屏幕**，固件要收到「设置时间」才会重绘。
> 所以 App 在改完这些选项后会**自动补发一次对时命令**，屏幕才会真的变化。若仍无反应，手动点一次「日历模式 / 时钟模式」即可。

### 4.5 「修复时间更新闪烁」

部分价签在每次时间刷新时 LED 会闪一下。
点「修复时间更新闪烁」后，App 会**按原厂调试命令的格式发送 `2300`**（命令字节 `0x23 LED_CTRL` + 负载 `0x00`，即把 LED 设为不闪烁），并立刻重刷时钟画面。发送后下拉框会同步回显为「不闪烁」。

### 4.6 外观与字体

**圆弧 / 方框**：设置页一键切换全 App 的圆角大小（卡片、按钮、输入框、下拉框全部跟着变），背景色保持不变，默认「圆弧」。

**字体（5 选 1，全局生效）**

| 选项 | 实际使用 | 来源 |
|---|---|---|
| OneShot | OneShot | App 内置 |
| 我的世界像数字体 | 我的世界像数字体 | App 内置 |
| **等宽字体** | **JetBrains Mono** | 免费字体站下载，**内置进 APK**，不联网也能用 |
| **系统默认字体** | **空字体 + Roboto 回退** | 自制空字体（无任何字形）→ 触发系统字体回退 → 显示**安卓原生 Roboto**，不受主题商店字体影响 |
| 跟随系统 | 系统当前字体 | 就是主题商店装的那套 |

字体**全局生效**：主页、设置页、搜索列表、每一个列表条目、下拉框弹出的选项、确认弹窗、日期选择器，全部使用同一套字体，不会出现「一部分自带字体、一部分系统字体」的割裂感。

> ⚠️ 自带字体（OneShot / 我的世界像数字体 / JetBrains Mono）**不含汉字字形**，汉字会回退到系统中文字体。这是字体本身的限制，数字和字母则是自带字体的效果。要让中文也变成等宽，需要额外内置一套含中文的等宽字体（体积会明显变大）。

### 4.7 运行架构（32 / 64 位）

设置页可切换 32 位 / 64 位运行模式，内核库（CRC32 + 墨水屏 RLE 编码）在两种模式下都能加载。

- **系统只支持 64 位** → 自动强制 64 位（不可选 32 位）
- **系统只支持 32 位** → 自动 32 位
- **系统两种都支持** → 默认 32 位，可手动改

切换后需要重启 App 生效。

## 五、隐私

- **不联网**：APK 里没有 `INTERNET` 权限，代码里没有任何网络请求
- **不收集数据**：不读取通讯录、不读取相册（选图是你主动从系统相册里挑的）、不上报统计
- **只连你的价签**：蓝牙扫描只用于发现 `DLG-` / `NRF-EPD-` / `ESL-` 开头的设备，其它设备的名称和地址都不会被读取
- 换字体、换外观等设置只存在本机

## 六、常见问题

**Q：扫描页一直搜不到设备？**
A：① 确认价签已开机（部分价签长时间不操作会休眠）；② Android 11 及以下请开启定位（系统强制要求）；③ 确认蓝牙已开；④ 远离其它蓝牙设备后重试。

**Q：改了日历主题，屏幕完全没变化？**
A：App 已经自动补发对时命令。若仍无变化，请手动点一次「日历模式」；另外确认当前是不是处在「图片模式」（图片模式下主题不生效），可先点「时钟模式」再点「日历模式」。

**Q：改 LED 之后屏幕没变？**
A：同上，LED 只在时钟模式下有意义；点一次「时钟模式」即可生效。若还是闪，用「修复时间更新闪烁」。

**Q：时间不准 / 时间刷新时闪？**
A：先点「时钟模式」重新对时；DLG 设备可用设置页的「时间校准」微调 ±秒。

**Q：图片槽位显示为空？**
A：设备没上报槽位信息（部分固件不支持多图轮播）。点「刷新槽位」重试；确认固件版本支持多图功能。

**Q：切了字体只有数字变了，汉字没变？**
A：正常。内置字体没有汉字字形，汉字只能回退系统中文字体。想让中文也变样，需要内置含中文的字体。

**Q：换字体后没有立刻生效？**
A：设置页改完会立即套用当前页面；正在显示的其它页面在返回时会自动重新套用。

**Q：连接后 App 提示「未找到 EPD 服务」？**
A：设备名不是三种前缀之一（可能不是厂家价签），或该价签用的是另一套私有协议。

## 七、给开发者

### 目录结构

```
app/src/main/java/com/breeze/epd/
├─ MainActivity.kt          主页：连接、设备控制、屏幕内容入口
├─ ScanActivity.kt          全屏蓝牙搜索（竖排列表 + 信号强度）
├─ SettingsActivity.kt      设置页：字体、外观、架构、设备选项
├─ ImageActivity.kt         图片导入：面板/颜色/抖动/预览/下发
├─ TextActivity.kt          新建文本
├─ SlotActivity.kt          图片槽位管理（显示/删除/轮播）
├─ BaseActivity.kt          统一字体、关闭转场动画
├─ ble/
│  ├─ EpdProtocol.kt        指令集 + 三家族 GATT 定义
│  ├─ EpdManager.kt         连接管理、串行写队列、notify 解析
│  ├─ EpdOptions.kt         设备选项下发（含补发对时）
│  └─ EpdImageSender.kt     图片/槽位下发（NRF 与 ESL 两套协议）
├─ image/
│  ├─ EpdImage.kt           面板、调色板、位图打包
│  └─ ImagePrep.kt          缩放、旋转、5 种抖动算法
├─ native/EpdCore.kt        JNI：CRC32 + RLE 编码（4 套 ABI）
└─ util/Lunar.kt            1900–2100 农历换算（DLG 对时用）
```

### 协议要点

| 家族 | 服务 / 特征 | 关键指令 |
|---|---|---|
| NRF | `62750001-…` / 写通知 `62750002-…` / 只读 `62750003-…` | `0x20` 对时、`0x23` LED、`0x25` 蓝牙广播、`0x26/0x27` 主题、`0x28` 温度、`0x30` 传图、`0x4E/0x41/0x42` 槽位烧录、`0x4F/0x50/0x51/0x53` 槽位操作 |
| DLG | `0xFF00` / 写读 `0xFF01` / 只读电压 `0xFF02` | `0x90` 12/24 时制、`0x91` 对时（含农历）、`0x92` 时间校准 |
| ESL | `13187b10-…`（数据）+ `00001f10-…`（设置） | 设置通道 `0xDD` 对时、`0xE1` 模式/时钟样式、`0xE2` 应用；数据通道 `0x00` 清屏、`0x02` 开始、`0x03` 数据块（列主序位图）、`0x01` 结束 |

### 构建

```bash
export JAVA_HOME=<jdk17>
export ANDROID_HOME=<android-sdk-34>
./gradlew assembleRelease          # 产物：app/build/outputs/apk/release/app-release.apk
./gradlew recordPaparazziDebug     # 生成 UI 预览图（无模拟器环境下的像素级校验）
```

签名：`app/keystore/epd.jks`（别名 `epd`），APK v2 签名。
